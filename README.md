# LR Quick Keys — downloads

One-key slider nudges, reset keys, Auto WB / Auto Tone, and Upright keys for **Adobe Lightroom Classic** on macOS.

**[Download the latest version →](https://github.com/Forfie/lr-quick-keys-releases/releases/latest)**

1. Open the `.dmg` and drag **LR Quick Keys** into **Applications**.
2. Open it. The ± icon appears in the menu bar and installs its Lightroom plugin.
3. Quit and reopen Lightroom Classic.
4. Set your keys in **Settings…** from the ± menu.

The app is signed and notarized by Apple, so it opens without security warnings. It keeps itself up to date: see **Settings → Updates**. Requires macOS 13 or later and Lightroom Classic.

This repository only hosts release downloads.
